# SubZap

SubZap is a privacy-focused subscription management platform designed to help users organize, monitor, and understand their recurring subscriptions in one place.

## Features

- 🔐 Secure authentication with Email/Password and Google Sign-In
- 📧 Email verification and password reset
- 📱 Subscription catalog with popular services
- 💰 Standard subscription pricing in INR
- ✏️ Custom pricing for student discounts, offers, and family plans
- 📅 Renewal date management
- 🔔 Subscription intelligence and money-saving insights
- ☁️ Cloud synchronization
- 🛡️ Client-side encryption for sensitive subscription data
- 🤖 Interactive ZapBot assistant

## Tech Stack

- React
- TypeScript
- Firebase Authentication
- Cloud Firestore
- Vite
- Tailwind CSS

## Project Status

SubZap is currently under active development, with the focus on building a polished and privacy-conscious subscription management experience.

## Vision

The goal of SubZap is to go beyond simply tracking subscriptions by helping users understand their recurring expenses and make better decisions about the services they pay for.
